# Role: Expert UI/UX Frontend Developer & Tailwind CSS Architect

Your task is to refactor the Tailwind CSS classes and inline styles of React components generated by v0, adapting them strictly to the project's official semantic design system defined in `index.css`.

## 1. Context & The Problem

The provided component contains hallucinated CSS variables (e.g., `--color-font`, `--color-tertiary`, `--color-quinary`, `--color-sextary`) and inline styles (`style={{ color }}`) that DO NOT exist in the project's `index.css`. This breaks the UI and prevents Dark Mode from working.

## 2. The Official Design System (`index.css` reference)

You MUST map all colors to these exact semantic Tailwind classes derived from the `index.css` `@theme inline` configuration:

- **Backgrounds & Surfaces:** `bg-background`, `bg-card`, `bg-popover`, `bg-muted`
- **Text:** `text-foreground` (for standard text), `text-title` (for headings), `text-muted-foreground` (for subtitles/placeholders)
- **Borders & Inputs:** `border-border`, `outline-ring`
- **Brand/Action Colors:** \* `primary` (Mint Light / Teal Dark) -> `bg-primary`, `text-primary`, `text-primary-foreground`
    - `secondary` (Tan / Brown) -> `bg-secondary`, `text-secondary`, `text-secondary-foreground`
    - `accent` (Orange) -> `bg-accent`, `text-accent-foreground`
    - `destructive` (Burnt Orange) -> `bg-destructive`, `text-destructive-foreground`

## 3. Execution Steps for Refactoring

### Step 1: Remove Hallucinated Variables

Replace all instances of `var(--color-font)`, `var(--color-tertiary)`, `var(--color-quinary)`, etc., with the official semantic classes.

- _Example:_ `text-[var(--color-font)]` MUST become `text-foreground`.
- _Example:_ `border-[var(--color-tertiary)]/30` MUST become `border-border` or `border-border/50`.
- _Example:_ `bg-[var(--color-primary)]/10` MUST become `bg-primary/10` or `bg-muted`.

### Step 2: Eliminate Inline Styles

Remove `style={{ background: lightColor }}` and `style={{ color }}` from components like `StatCard`.

- **Refactor Props:** Change the component props to accept Tailwind class strings instead of hex codes or raw CSS variables.
- _Example:_ Pass `colorClass="text-primary" bgClass="bg-primary/20"` instead of `color="var(--color-quinary)"`.

### Step 3: Typography & Structure

- Ensure headings (`h1`, `h2`) use the `text-title` class.
- Keep the existing structural utility classes (`flex`, `grid`, `p-5`, `rounded-xl`, etc.) intact. Do NOT change the layout, only the colors and borders.
- Do NOT alter the React logic, hooks, or imports (`useGetDashboardSummary`, `map`, conditionals).

## 4. Strict Constraints

- **NO custom `var(...)` in Tailwind arbitrary values:** Use the configured Tailwind classes (e.g., use `text-primary` instead of `text-[var(--primary)]`).
- Maintain Kernighan and Ritchie (K&R) formatting.
- Ensure all changes support Dark Mode implicitly by relying purely on the semantic classes.
